# MJ Forms help

MJ Forms is how you put a question to people and get an answer back. You write the questions, decide
how the form looks, publish it, and send out a link that anyone can open without signing in — no
account, no password, on a phone or a laptop. The answers come back to you inside MemberJunction,
where you can read them one at a time, see what they add up to, export them, or have each one turn
into a record your team already works with. You do all of it in the **Forms** app. Nothing here
needs a developer.

## Start here

New to MJ Forms? Start with [Create your first form](get-started/first-form.md): about ten minutes,
ending with a real answer from a real link, which is the fastest way to understand the rest of this.

- [Get started](get-started/first-form.md) — one form, start to finish, and a tour of where
  everything lives.
- [Glossary](reference/glossary.md) — every word this help uses that you might not already have a
  meaning for, in the sense MJ Forms means it.
